# SSE pour informer les écrans

Statut : choix pédagogique implémenté dans la correction.

## Décision

Les commandes utilisent HTTP classique. Après commit, le serveur signale une modification. Le front recharge l’état au message ready et lors d’un changement.

## Conséquences et alternatives

Le flux n’est pas un journal durable. Plusieurs instances nécessitent diffusion partagée et resynchronisation. Le polling reste une alternative simple.

## Vérification

Rejouer les tests et observer le parcours correspondant avant de proposer un changement.
